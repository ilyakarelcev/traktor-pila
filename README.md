# Трактор-пила

Собранная веб-версия игры (Three.js), выложенная, чтобы в неё можно было сыграть по ссылке:
https://ilyakarelcev.github.io/traktor-pila/

Здесь только готовая сборка для игры (`npm run build:public`, версия 1.1.2): без инструментов разработки и без
аналитики, исходники лежат в отдельном закрытом репозитории.
Лучше всего играть с телефона: на телефоне игра идёт только вертикально. На компьютере тоже работает: WASD или
стрелки, или зажми мышь и тяни.

Голоса персонажей — записи «бла-бла» с freesound.org (CC0), звуки — CC0.

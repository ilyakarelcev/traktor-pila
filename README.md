# Трактор-пила

Собранная веб-версия игры (Three.js), выложенная, чтобы в неё можно было сыграть по ссылке:
https://ilyakarelcev.github.io/traktor-pila/

Здесь только готовая релизная сборка (`npm run release`, версия 1.1.1), исходники лежат в отдельном закрытом репозитории.
Лучше всего играть с телефона в вертикальной ориентации; на компьютере тоже работает: WASD или стрелки, или зажми мышь и тяни.

Голоса персонажей — записи «бла-бла» с freesound.org (CC0), звуки — CC0.
